# المنفذ الصامت للمقاولات العامة — Landing Page

صفحة هبوط (Landing Page) لمؤسسة **المنفذ الصامت للمقاولات العامة** — تنسيق المواقع، الزراعة، وشبكات الري.

- صفحة واحدة `index.html` بدون أي build — HTML + CSS + JS.
- عربي RTL، متجاوبة مع الموبايل.
- معرض مشاريع بفلترة وعارض صور، ونموذج طلب عرض سعر يُرسل عبر واتساب.
- الصور في `assets/img/` مأخوذة من بروفايل الشركة.

## النشر
منشورة عبر GitHub Pages من فرع `main`.
